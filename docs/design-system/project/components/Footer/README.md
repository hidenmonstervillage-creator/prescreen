# Footer

The disclaimer line at the foot of every screen: "Karma organizes and cites documents. It does not interpret, recommend or decide."

## Recipe

`border-t border-line bg-surface`; inner `mx-auto max-w-content px-5 py-4 text-small text-ink-secondary`. A second, right-aligned line may credit the data source ("Trials from ClinicalTrials.gov").

## Rules

- The sentence is fixed. Don't shorten, rephrase or hide it, and keep it at 14px like everything else.
- It sits on every screen, the landing page and the evidence panel's page included.
