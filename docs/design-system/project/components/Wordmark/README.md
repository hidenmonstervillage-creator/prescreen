# Logo and wordmark

The Karma logo, Twin: a disc with two spiral grooves, drawn as dots from 64px tall and up and as one solid shape below that, with the name beside it or on its own.

## Two drawings of one mark

| | Dotted | Solid |
| --- | --- | --- |
| What it is | 330 dots on a sunflower layout with two spiral grooves left open; the dots grow from the centre outward and step through the brand palette | The same disc and the same two spirals as one filled shape, the grooves a little wider |
| Use it | 64px tall and up: title slides, the cover, the landing page | Below 64px: the app header, favicons, small print |
| On light | navy at the centre to lavender at the rim | `accent` |
| On dark | mist at the centre to cobalt at the rim | `periwinkle` |

Under 64px a dot shrinks below one pixel and the grooves close, which is why the solid drawing exists. Both drawings have the same outline and their lockups share one geometry, so one swaps for the other without moving the name.

## Which file

| Where | File |
| --- | --- |
| App header, 64px, light | `karma-lockup-solid.svg`, 28px tall |
| Landing page header, dark | `karma-lockup-solid-reversed.svg` |
| Landing page, large, on the plain dark ground | `karma-lockup-reversed.svg`, 64px tall or more |
| Title slide, light or dark | `karma-lockup.svg` or `karma-lockup-reversed.svg` |
| Tab, bookmark, app icon | `karma-icon.svg` |
| One colour | `karma-mark-mono.svg` |
| A space too narrow for a lockup | the mark alone, dotted or solid by its size |

## Rules

- Clear space on every side: the height of the "k".
- Smallest sizes: dotted mark 64px tall, solid mark 16px, solid lockup 20px tall, the name alone 14px tall.
- Use the files. Don't redraw the mark, rebuild the lockup from type, stretch, rotate or outline it, or add a shadow or a glow.
- Colours are the files' own, or `karma-mark-mono.svg` in the text colour. Never put the mark in a state colour or in violet.
- On dark, use the `-reversed` files on `brand-ground`, on the plain ground and never over the dot light.
- In running text write Karma with a capital K, in the surrounding type.
